# 2026-10-07 NPC 更新应用说明

## 基线和内容

对应 demo3_UE58 1.5 完整工程、UE 5.8.3 Windows。本仓库仍是增量仓库，需要完整工程原有的 Enchanted Forest、KindWitch、Natta、Fawnia 和 Witch_House 资产。

本批包含三个 NPC 蓝图、五组原生类、导航碰撞模型副本、导航与碰撞配置，以及完整的 **Demo_Day 关卡文件**。该关卡采用 Git LFS。

- NPC 在道路附近连续选择可达路段，不再执行 NPC01–07 固定目的地巡逻。
- 路段失败时退避、短暂避开失败位置并重新选路。
- 三个角色恢复原始走路动画，移除程序拼接的下蹲骨骼后处理。
- Natta、Fawnia 模型高度改为 -88 cm；模型朝向为 Yaw=-90；常规步行速度为 93.75 cm/s。
- 小装饰物不阻挡 NPC，新增 216 个小物件放行；地面、大树、岩壁、建筑等仍保留碰撞和导航。
- F6 切换玩家/NPC右肩观察；F7 换 NPC；F8 物理下蹲预览；F9 显示导航路径。
- 玩家约 2.5 米内按 E 与 NPC 交谈；E/Esc 结束后恢复漫游。目前是基础问候。
- 已从关卡删除 NPC01–NPC07 七个箱子。旧 Arrival 辅助点仍在地图中，但不再控制漫游。

## 应用顺序

1. 获取本仓库后运行 `git lfs install`、`git lfs pull`。网页下载 ZIP 可能只包含 LFS 指针，请确认 Demo_Day.umap 约 157 MB，而不是几行文本。
2. 保存并关闭 UE，备份完整工程。关卡覆盖会替换该关卡中已有的本地摆放与编辑。
3. 复制本批 `Source` 和三个 NPC 蓝图、两个导航模型到完整工程同名相对路径。
4. 合并 DefaultEngine.ini 的 RecastNavMesh、NavigationSystemV1、CollisionProfile 三个区段。ForestNPC 使用 ECC_GameTraceChannel1；目标工程若已占用此通道，需要同时调整原生代码和配置。不要覆盖目标工程的访问令牌或无关设置。
5. 编译 demo3_UE58Editor，再应用 Demo_Day.umap。打开关卡后按需要构建导航。
6. 本批无需覆盖原模型或原动画，也无需新增 ABP_CrouchPose_* 资产。这些实验性骨骼后处理已停用。
7. 既有 DialogueMemoryTable 插件和 uproject 插件项沿用前置批次，本批不替换或删除它们。

## 验证来源与限制

- 当前开发会话中，Windows UE 5.8.3 原生模块编译成功。
- 漫游改造阶段的 PIE 记录确认三 NPC 连续完成多个路段；基础交谈入口成功暂停 NPC 和玩家移动，结束后解除限制。
- 最后几次修正（移除骨骼后处理、小物件专用碰撞、模型朝向、93.75 步行速度、删除箱子）已在编辑器设置、读取确认并保存；没有重新运行完整 PIE 回归，也没有打包测试。
- Git 仓库只是增量，不能独立打开完整项目；地图中原有资源仍依赖匹配工程。
- 物理下蹲保留，独立的自然下蹲动画尚未接入；没有完整足部 IK，坡面脚部仍可能有局部误差。
- F6 观察相机自动跟随角色朝向；它是 NPC 调试观察功能。E 问候尚未接入剧情对话或任务系统，也未检查与原采摘 E 键的冲突。

## 回退

完整工程恢复应用前备份；新增类被 NPC 蓝图和地图引用，回退时须一起恢复地图、三个蓝图、模块依赖与碰撞配置。
